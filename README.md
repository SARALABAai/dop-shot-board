# DOP Shot Board

Storyboard and lens planner for videographers / DOPs shooting music videos and short films. Built by SARA Lab Group 2.

- Add a location photo to each shot and pick a lens: see the field of view and a drag-able frame overlay on the photo.
- Load a song: it finds the BPM and sections, then builds a storyboard with shot size, lens, angle, movement and composition.
- Works offline. Installable on Android (Chrome → Install app) when served over https; open `index.html` directly on a computer.

Files: `index.html` (the whole app), `manifest.webmanifest` + `sw.js` + icons (install/offline), `example-photos/` (Johannesburg examples, see `CREDITS.txt` for licences and authors).
